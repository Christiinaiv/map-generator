# Генератор двовимірних ігрових карт

Процедурний генератор збалансованих ігрових карт для двох гравців
на основі **діаграм Вороного**.

---

## Запуск проєкту

Для роботи генератора потрібен Python 3.10+ та залежності:

- `numpy`
- `scipy`
- `shapely`
- `matplotlib`

Встановлення:

```bash
pip install -r requirements.txt
```

### Файли проєкту

Після клонування всі файли мають знаходитися в одному каталозі:

- `islands.py` — ядро генерації
- `map_gui.py` — графічний інтерфейс
- `test_generator.py` — юніт-тести
- `benchmark.py` — бенчмарк
- `requirements.txt` — залежності

---

## Використання

### Графічний інтерфейс

```bash
python map_gui.py
```

Налаштуйте параметри та натисніть **«ГЕНЕРУВАТИ КАРТУ»**:

- Кількість гравців: 2 (in progress)
- Кількість островів: 3–5
- Кількість архіпелагів: 3–5
- Seed карти: ціле число або порожньо для випадкового
- Об'єкти: мости, порти, дороги, будівлі

Карта автоматично зберігається у PNG поряд зі скриптом.

### Консольний режим

```bash
python islands.py
```

### Тести та бенчмарк

```bash
python test_generator.py  
python benchmark.py        
```

- **Експорт JSON** — координати всіх секторів у `.json`
